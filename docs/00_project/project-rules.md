# Project Rules

## Language

- Project documentation: English
- Code, identifiers, comments: English
- Codex prompts: English
- Conversation and design discussion: German is fine
- Game UI labels: English for the first development phase

## Anti-drift rule

Every new feature must directly support the single-room grow loop.

If it does not, document it in the backlog and do not implement it.

"Prepare it for later" is not a valid reason during Iteration 1.

## Safety boundary

WB VibeEd uses abstract game values and fictional plant lines. It must not provide real-world cultivation guidance.

Do not add:

- real strain names
- exact real cultivation parameters
- actionable recipes
- step-by-step growing advice
- real legal or compliance advice
