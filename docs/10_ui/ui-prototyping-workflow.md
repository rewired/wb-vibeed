# UI Prototyping Workflow

The UI is specified visually before implementation.

## Workflow

1. Define the screen purpose.
2. Generate or sketch a visual mockup.
3. Review information hierarchy and player actions.
4. Write a screen contract.
5. Implement only against the mockup and screen contract.
6. Reject frontend additions that are not covered by the contract.

## Core screens for Iteration 1

1. Operations Cockpit
2. Setup / Room Configuration
3. Batch Report

## Visual style corridor

Dark industrial control dashboard. Technical, readable, slightly worn. Green and amber status accents. Few strong contrasts. No farm cartoon aesthetic. No stoner clichés. No cyberpunk overkill. No table hell.

The UI should feel like an operations console, not a lifestyle shop.
