# Image Prompt – Batch Report Mockup v0.1

Create a 16:9 UI mockup for the batch report screen of a fictional deterministic grow operations simulator.

The screen explains the result of one completed batch and motivates another run.

Visual direction:

- dark industrial reporting dashboard
- strong summary panel
- readable charts and diagnosis cards
- green/amber status accents
- no celebratory casino style
- no real cultivation instructions

Visible UI regions:

- top summary with batch label and management grade
- large result cards: yield index, quality index, stress average, energy cost, profit index
- center stress and stability trend chart
- right diagnosis list with impact labels
- bottom comparison to previous run and next-run action
