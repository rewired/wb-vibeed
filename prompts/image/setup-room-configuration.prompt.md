# Image Prompt – Setup / Room Configuration Mockup v0.1

Create a 16:9 UI mockup for the setup screen of a fictional deterministic single-room grow operations simulator.

The player reviews one small room, a tiny device set, and one fictional batch option before starting a run.

Visual direction:

- dark technical setup console
- readable panels
- no shop interface
- no large device catalog
- no real strain database
- no real-world cultivation advice
- calm planning mood before simulation starts

Visible UI regions:

- top project/run header
- left simplified room layout
- center device summary cards: light, climate, irrigation, sensor
- right batch selection and forecast
- bottom start action and risk/cost preview
