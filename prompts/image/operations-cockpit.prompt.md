# Image Prompt – Operations Cockpit Mockup v0.1

Create a 16:9 UI mockup for a dark industrial operations dashboard for a fictional deterministic grow operations simulator.

The screen is the main Operations Cockpit for one room, one zone, and one active batch. It should feel like a technical control room interface, not a farm game, not a lifestyle shop, and not a cannabis poster.

Visual direction:

- dark industrial control dashboard
- readable dense UI, not cluttered
- slightly worn technical console mood
- green and amber status accents
- minimal neon
- subtle room visualization on the left
- telemetry cards in the center
- operating mode controls and alerts on the right
- event log and cost strip at the bottom
- no real-world cultivation values
- no exact recipes
- no cartoon style
- no cyberpunk overkill

Include visible UI regions:

- top status bar with simulation day, tick, phase, and speed
- left room/zone visual with batch status
- center telemetry panel with abstract values such as light, temperature, humidity, water, nutrients, stress, growth, maturity
- right control panel with abstract modes: Light Eco/Balanced/Push, Climate Eco/Stable/Aggressive, Irrigation Conserve/Balanced/Saturate
- alert stack with short diagnostic messages
- bottom event log and operating cost summary

The mockup should prioritize clarity and hierarchy over visual spectacle.
